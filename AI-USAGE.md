# AI usage

OpenAI Codex assisted with requirements breakdown, implementation planning,
React/TypeScript components, Spring Boot APIs, migrations, tests, debugging,
deployment configuration and documentation. AI was also used to run CLI checks
and prepare GitHub PR descriptions. This was substantial implementation
assistance, not only spelling or completion assistance.

The project owner supplied the assessment, chose the React/Spring monolith
approach, reviewed milestones and approved deployment. AI-generated code and
design choices should be reviewed like other contributions. Passing automated
tests does not prove production security, accessibility or infrastructure
capacity. The owner remains responsible for the submitted work and explanation.

No real creator, customer, payment or identity data is included in sample data.
Do not submit real identity documents to the demo. Deployment/account secrets
belong in ignored local files or provider environment settings, never this repo.

Typical instructions used during development included implementing small PRs,
following controller/service/impl/model/dto/config/exception/repository layers,
adding Swagger, enforcing creator ownership and verification before publishing,
and deploying the React demo without a backend. This file summarizes usage;
it is not a verbatim prompt transcript.

Verification commands and reproducible reviewer steps are in README.md.
Approximate human effort was not time-tracked; the owner should add a truthful
estimate before submitting rather than attributing AI runtime to human work.
